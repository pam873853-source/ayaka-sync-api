Privacy Policy

This policy describes the data handled by this Ayaka Sync API deployment. Operators who self-host should review and adapt it for their jurisdiction.

Data we collect

  • Account data — username, email, display name and preferences you provide.
  • Credentials — passwords are stored only as Argon2id hashes; API keys only as HMAC-SHA256 hashes plus a short display prefix.
  • Usage data — for each API request: endpoint, method, status code, response time, key ID, IP address, user agent and request ID.
  • Security events — sign-ins, failed sign-ins, key changes and settings changes in an append-only activity log.

What we never store

  • Full API keys after they are shown once, plaintext passwords, Authorization headers or request bodies.

How data is used

Data is used only to authenticate you, enforce rate limits and permissions, show analytics and activity in your dashboard, and protect the service from abuse. No data is sold or shared with advertisers.

Cookies

Only essential cookies are set: HttpOnly session cookies for authentication and a CSRF token cookie. No analytics or tracking cookies are used.

Retention & deletion

You can delete individual API keys at any time, and delete your entire account from Settings → Danger Zone, which removes your keys, usage logs, sessions and activity.

Infrastructure

Data is stored in PostgreSQL (Neon) and the application runs on Vercel, with TLS in transit.

Contact

Questions about this policy should be sent to the operator of this deployment. See Help & support.
