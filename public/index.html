Features

Everything you need to run API access safely.

One place to issue keys, enforce limits and understand how your API is used — without building it yourself.

Secure API Key Management

Keys are generated with a CSPRNG, shown once, and stored only as an HMAC-SHA256 hash.

Real-time Usage Monitoring

Watch requests arrive minute by minute with automatic, visibility-aware refresh.

Request Analytics

Volume, success rate, latency and peak traffic — broken down by endpoint and key.

API Access Control

Granular read, write, delete, analytics and profile permissions plus endpoint allow-lists.

Rate Limiting

Per-key limits backed by PostgreSQL with standard X-RateLimit-* and Retry-After headers.

Developer-friendly Documentation

cURL, Python and JavaScript examples, an OpenAPI reference and a live endpoint tester.

Secure Authentication

Argon2id passwords, HttpOnly cookie sessions, CSRF protection and brute-force lockout.

Reliable Infrastructure

Serverless FastAPI on Vercel with Neon PostgreSQL, health checks and resilient usage logging.

How it works

From sign-up to first request in minutes.

Create your account

Register with a username, email and a strong password.

Generate an API key

Choose environment, permissions, rate limit and expiration.

Connect your application

Send the key in the Authorization header from your backend.

Monitor API requests

See every call, status code and response time in your dashboard.

Manage usage and security

Rotate, disable or revoke keys and review the audit log at any time.
